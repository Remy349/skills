# sqlc persistence adapter guide

Targets sqlc 1.31 generating code for `pgx/v5`, with goose migrations as the schema source. sqlc turns annotated SQL into type-safe Go at build time: you keep writing SQL, the compiler checks the Go side. The generated package is a persistence detail of the adapter, exactly like pgx rows; the adapter still maps to `domain.OrderSnapshot`. The domain and use cases are the ones from `../idioms.md`.

## 1. Detection and setup

A `sqlc.yaml` (or `sqlc.json`) at the root, generated files with `// Code generated by sqlc. DO NOT EDIT.`, and `github.com/jackc/pgx/v5` in `go.mod`.

```yaml
# sqlc.yaml
version: "2"
sql:
  - engine: postgresql
    schema: migrations              # sqlc reads goose files and ignores the Down sections
    queries: internal/orders/adapters/outbound/postgres/queries.sql
    gen:
      go:
        package: sqlcdb
        out: internal/orders/adapters/outbound/postgres/sqlcdb
        sql_package: pgx/v5
        emit_pointers_for_null_types: true
        overrides:
          - db_type: timestamptz
            go_type: time.Time
          - db_type: timestamptz
            nullable: true
            go_type:
              type: time.Time
              pointer: true
```

- `schema: migrations` points sqlc at the goose files (`pgx.md`, sections 2 and 7, shows them); there is no second copy of the schema.
- `sql_package: pgx/v5` generates code on pgx, so the unit of work and the pool are the same as in `pgx.md`.
- The overrides map `timestamptz` to `time.Time` (and `*time.Time` when nullable) instead of `pgtype.Timestamptz`.
- The generated package `sqlcdb` sits **inside** the adapter: only `postgres` imports it.

Run `sqlc generate` after changing a query or a migration, commit the generated code, and check it in CI with `sqlc diff` (or `sqlc generate` followed by `git diff --exit-code`). `sqlc vet` catches queries that no longer match the schema.

## 2. Queries

```sql
-- internal/orders/adapters/outbound/postgres/queries.sql
-- name: GetOrder :one
SELECT customer_id, status, currency, placed_at, payment_id, version
FROM orders
WHERE id = $1;

-- name: ListOrderLines :many
SELECT sku, quantity, unit_price_cents
FROM order_lines
WHERE order_id = $1
ORDER BY position;

-- name: InsertOrder :exec
INSERT INTO orders (id, customer_id, status, currency, total_cents, placed_at, payment_id, version)
VALUES ($1, $2, $3, $4, $5, $6, $7, 1);

-- name: InsertOrderLine :exec
INSERT INTO order_lines (order_id, position, sku, quantity, unit_price_cents)
VALUES ($1, $2, $3, $4, $5);

-- name: UpdateOrder :execrows
UPDATE orders
SET status = @status, payment_id = @payment_id, version = version + 1
WHERE id = @id AND version = @version;
```

`:one`, `:many`, `:exec` and `:execrows` choose the generated signature; `:execrows` returns the affected row count, which the optimistic lock needs. `@name` gives a parameter a readable name in the generated params struct.

## 3. Repository adapter

The adapter wraps the generated `Queries`, maps generated rows to the domain snapshot, and translates errors. Generated types never leave the package.

```go
// internal/orders/adapters/outbound/postgres/order_repository.go
// Package postgres implements the orders outbound ports with sqlc-generated queries on pgx.
// Generated types live in sqlcdb and never leave this package.
package postgres

import (
	"context"
	"errors"
	"fmt"

	"github.com/jackc/pgx/v5"
	"github.com/jackc/pgx/v5/pgconn"

	"shop/internal/orders/adapters/outbound/postgres/sqlcdb"
	"shop/internal/orders/domain"
)

// OrderRepository implements app.OrderRepository. db is a *pgxpool.Pool or a pgx.Tx.
type OrderRepository struct {
	q *sqlcdb.Queries
}

func NewOrderRepository(db sqlcdb.DBTX) *OrderRepository {
	return &OrderRepository{q: sqlcdb.New(db)}
}

func (r *OrderRepository) Get(ctx context.Context, id domain.OrderID) (*domain.Order, error) {
	row, err := r.q.GetOrder(ctx, string(id))
	if errors.Is(err, pgx.ErrNoRows) {
		return nil, fmt.Errorf("%w: %s", domain.ErrOrderNotFound, id)
	}
	if err != nil {
		return nil, fmt.Errorf("get order %s: %w", id, err)
	}
	stored, err := r.q.ListOrderLines(ctx, string(id))
	if err != nil {
		return nil, fmt.Errorf("get order %s lines: %w", id, err)
	}
	lines := make([]domain.OrderLine, 0, len(stored))
	for _, l := range stored {
		// Stored rows were valid when written; an error here means corrupt data.
		price, err := domain.NewMoney(l.UnitPriceCents, row.Currency)
		if err != nil {
			return nil, fmt.Errorf("order %s has an invalid stored price: %w", id, err)
		}
		line, err := domain.NewOrderLine(l.Sku, int(l.Quantity), price)
		if err != nil {
			return nil, fmt.Errorf("order %s has an invalid stored line: %w", id, err)
		}
		lines = append(lines, line)
	}
	s := domain.OrderSnapshot{
		ID:         id,
		CustomerID: row.CustomerID,
		Lines:      lines,
		Status:     domain.Status(row.Status),
		PlacedAt:   row.PlacedAt.UTC(),
		Version:    int(row.Version),
	}
	if row.PaymentID != nil {
		s.PaymentID = *row.PaymentID
	}
	return domain.RehydrateOrder(s), nil
}

func (r *OrderRepository) Add(ctx context.Context, order *domain.Order) error {
	s := order.Snapshot()
	total := order.Total()
	err := r.q.InsertOrder(ctx, sqlcdb.InsertOrderParams{
		ID:         string(s.ID),
		CustomerID: s.CustomerID,
		Status:     string(s.Status),
		Currency:   total.Currency(),
		TotalCents: total.Amount(),
		PlacedAt:   s.PlacedAt,
		PaymentID:  nullIfEmpty(s.PaymentID),
	})
	var pgErr *pgconn.PgError
	if errors.As(err, &pgErr) && pgErr.Code == "23505" { // unique_violation
		return fmt.Errorf("%w: %s", domain.ErrDuplicateOrder, s.ID)
	}
	if err != nil {
		return fmt.Errorf("insert order %s: %w", s.ID, err)
	}
	for i, line := range s.Lines {
		err := r.q.InsertOrderLine(ctx, sqlcdb.InsertOrderLineParams{
			OrderID:        string(s.ID),
			Position:       int32(i),
			Sku:            line.SKU(),
			Quantity:       int32(line.Quantity()),
			UnitPriceCents: line.UnitPrice().Amount(),
		})
		if err != nil {
			return fmt.Errorf("insert order %s line %d: %w", s.ID, i, err)
		}
	}
	return nil
}

func (r *OrderRepository) Update(ctx context.Context, order *domain.Order) error {
	s := order.Snapshot()
	affected, err := r.q.UpdateOrder(ctx, sqlcdb.UpdateOrderParams{
		ID:        string(s.ID),
		Status:    string(s.Status),
		PaymentID: nullIfEmpty(s.PaymentID),
		Version:   int32(s.Version),
	})
	if err != nil {
		return fmt.Errorf("update order %s: %w", s.ID, err)
	}
	if affected == 0 {
		return fmt.Errorf("%w: %s (version %d)", domain.ErrStaleOrder, s.ID, s.Version)
	}
	return nil
}

func nullIfEmpty(s string) *string {
	if s == "" {
		return nil
	}
	return &s
}
```

## 4. Unit of Work

`sqlcdb.New` accepts anything with `Exec`, `Query` and `QueryRow`, so `*pgxpool.Pool` and `pgx.Tx` both work. The unit of work is the same as with plain pgx:

```go
// internal/orders/adapters/outbound/postgres/unit_of_work.go
package postgres

import (
	"context"

	"github.com/jackc/pgx/v5"
	"github.com/jackc/pgx/v5/pgxpool"

	"shop/internal/orders/app"
)

// UnitOfWork implements app.UnitOfWork with one pgx transaction per call.
type UnitOfWork struct {
	pool *pgxpool.Pool
}

func NewUnitOfWork(pool *pgxpool.Pool) *UnitOfWork {
	return &UnitOfWork{pool: pool}
}

// Do commits when fn returns nil and rolls back on an error or a panic.
func (u *UnitOfWork) Do(ctx context.Context, fn func(tx app.Tx) error) error {
	return pgx.BeginFunc(ctx, u.pool, func(tx pgx.Tx) error {
		return fn(txRepositories{tx: tx})
	})
}

type txRepositories struct {
	tx pgx.Tx
}

func (t txRepositories) Orders() app.OrderRepository { return NewOrderRepository(t.tx) }
```

## 5. Error translation

sqlc returns pgx errors unchanged:

| Technology error | Translated to |
|---|---|
| `pgx.ErrNoRows` from a `:one` query | `domain.ErrOrderNotFound` |
| `*pgconn.PgError` with code `23505` | `domain.ErrDuplicateOrder` |
| `0` from an `:execrows` versioned update | `domain.ErrStaleOrder` |
| Anything else | wrapped with context, a 500 at the edge |

## 6. Optimistic concurrency

`UpdateOrder` is `:execrows` with `WHERE id = @id AND version = @version`; the repository turns `0` rows into `domain.ErrStaleOrder`.

## 7. Outbox, read queries and idempotency

The tables are the ones in `pgx.md`, section 7. Add the queries:

```sql
-- internal/orders/adapters/outbound/postgres/queries.sql (addition)
-- name: InsertOutboxMessage :exec
INSERT INTO outbox (id, event_type, payload) VALUES ($1, $2, $3);

-- name: LockPendingOutboxMessages :many
SELECT id, event_type, payload
FROM outbox
WHERE published_at IS NULL
ORDER BY occurred_at, id
LIMIT $1
FOR UPDATE SKIP LOCKED;

-- name: MarkOutboxMessagePublished :exec
UPDATE outbox SET published_at = now() WHERE id = $1;

-- name: ListOrdersForCustomer :many
SELECT id, status, total_cents, currency, placed_at
FROM orders
WHERE customer_id = @customer_id
  AND (sqlc.narg(after_placed_at)::timestamptz IS NULL
       OR (placed_at, id) < (sqlc.narg(after_placed_at)::timestamptz, @after_id::text))
ORDER BY placed_at DESC, id DESC
LIMIT @max_rows;

-- name: ReserveIdempotencyKey :execrows
INSERT INTO idempotency_keys (scope, key, fingerprint) VALUES ($1, $2, $3)
ON CONFLICT DO NOTHING;

-- name: GetIdempotencyKey :one
SELECT fingerprint, response FROM idempotency_keys WHERE scope = $1 AND key = $2;

-- name: CompleteIdempotencyKey :exec
UPDATE idempotency_keys SET response = $3 WHERE scope = $1 AND key = $2;

-- name: ReleaseIdempotencyKey :exec
DELETE FROM idempotency_keys WHERE scope = $1 AND key = $2;
```

`sqlc.narg(after_placed_at)` makes the parameter nullable (`*time.Time`), so the first page passes `nil`.

```go
// internal/orders/adapters/outbound/postgres/outbox.go
package postgres

import (
	"context"
	"fmt"

	"github.com/google/uuid"

	"shop/internal/orders/adapters/outbound/postgres/sqlcdb"
	"shop/internal/orders/domain"
	"shop/internal/orders/integrationevents"
)

// Outbox writes integration events in the caller's transaction.
type Outbox struct {
	q *sqlcdb.Queries
}

func NewOutbox(db sqlcdb.DBTX) *Outbox {
	return &Outbox{q: sqlcdb.New(db)}
}

func (o *Outbox) Add(ctx context.Context, events []domain.Event) error {
	for _, event := range events {
		msg, err := integrationevents.FromDomain(event)
		if err != nil {
			return err
		}
		err = o.q.InsertOutboxMessage(ctx, sqlcdb.InsertOutboxMessageParams{
			ID: uuid.Must(uuid.NewV7()).String(), EventType: msg.Type, Payload: msg.Payload,
		})
		if err != nil {
			return fmt.Errorf("insert outbox %s: %w", msg.Type, err)
		}
	}
	return nil
}
```

```go
// internal/orders/adapters/outbound/postgres/relay.go
package postgres

import (
	"context"
	"fmt"

	"github.com/jackc/pgx/v5"
	"github.com/jackc/pgx/v5/pgxpool"

	"shop/internal/orders/adapters/outbound/postgres/sqlcdb"
)

// Publisher sends one message to the broker. MessageID lets consumers deduplicate.
type Publisher interface {
	Publish(ctx context.Context, messageID, eventType string, payload []byte) error
}

// Relay publishes pending outbox rows, at least once. SKIP LOCKED lets several relays share the table.
type Relay struct {
	pool      *pgxpool.Pool
	publisher Publisher
	batchSize int32
}

func NewRelay(pool *pgxpool.Pool, publisher Publisher, batchSize int32) *Relay {
	return &Relay{pool: pool, publisher: publisher, batchSize: batchSize}
}

func (r *Relay) PublishPending(ctx context.Context) (int, error) {
	published := 0
	err := pgx.BeginFunc(ctx, r.pool, func(tx pgx.Tx) error {
		q := sqlcdb.New(tx)
		batch, err := q.LockPendingOutboxMessages(ctx, r.batchSize)
		if err != nil {
			return fmt.Errorf("lock pending outbox rows: %w", err)
		}
		for _, msg := range batch {
			if err := r.publisher.Publish(ctx, msg.ID, msg.EventType, msg.Payload); err != nil {
				return fmt.Errorf("publish %s: %w", msg.ID, err) // rolls back: the batch is retried
			}
			if err := q.MarkOutboxMessagePublished(ctx, msg.ID); err != nil {
				return fmt.Errorf("mark %s published: %w", msg.ID, err)
			}
			published++
		}
		return nil
	})
	if err != nil {
		return 0, err
	}
	return published, nil
}
```

```go
import (

	"shop/internal/orders/adapters/outbound/postgres/sqlcdb"

// OrderQueries implements the app.OrderQueries read port with one query and no aggregates.

	q *sqlcdb.Queries
}

func NewOrderQueries(db sqlcdb.DBTX) *OrderQueries {
	return &OrderQueries{q: sqlcdb.New(db)}
}

func (q *OrderQueries) ListForCustomer(ctx context.Context, customerID string, after *app.Position, limit int) ([]app.OrderSummary, error) {
	params := sqlcdb.ListOrdersForCustomerParams{CustomerID: customerID, MaxRows: int32(limit)}
	if after != nil {
		params.AfterPlacedAt, params.AfterID = &after.PlacedAt, after.OrderID
	}
	rows, err := q.q.ListOrdersForCustomer(ctx, params)
	if err != nil {
		return nil, fmt.Errorf("list orders of %s: %w", customerID, err)
	}
	summaries := make([]app.OrderSummary, len(rows))
	for i, row := range rows {
		summaries[i] = app.OrderSummary{
			OrderID: row.ID, Status: row.Status, TotalCents: row.TotalCents, Currency: row.Currency, PlacedAt: row.PlacedAt.UTC(),
		}
	}
	return summaries, nil
}
```

```go
// internal/orders/adapters/outbound/postgres/idempotency_store.go
package postgres

import (
	"context"
	"errors"
	"fmt"

	"github.com/jackc/pgx/v5"

	"shop/internal/orders/adapters/outbound/postgres/sqlcdb"
	"shop/internal/orders/app"
)

// IdempotencyStore implements app.IdempotencyStore. The primary key makes Reserve atomic.
type IdempotencyStore struct {
	q *sqlcdb.Queries
}

func NewIdempotencyStore(db sqlcdb.DBTX) *IdempotencyStore {
	return &IdempotencyStore{q: sqlcdb.New(db)}
}

func (s *IdempotencyStore) Reserve(ctx context.Context, scope, key, fingerprint string) (*app.IdempotencyRecord, error) {
	for range 3 { // a concurrent Release can delete the row between the insert and the select
		inserted, err := s.q.ReserveIdempotencyKey(ctx, sqlcdb.ReserveIdempotencyKeyParams{Scope: scope, Key: key, Fingerprint: fingerprint})
		if err != nil {
			return nil, fmt.Errorf("reserve idempotency key: %w", err)
		}
		if inserted == 1 {
			return nil, nil
		}
		row, err := s.q.GetIdempotencyKey(ctx, sqlcdb.GetIdempotencyKeyParams{Scope: scope, Key: key})
		if errors.Is(err, pgx.ErrNoRows) {
			continue
		}
		if err != nil {
			return nil, fmt.Errorf("read idempotency key: %w", err)
		}
		return &app.IdempotencyRecord{Fingerprint: row.Fingerprint, Response: row.Response}, nil
	}
	return nil, app.ErrRequestInProgress
}

func (s *IdempotencyStore) Complete(ctx context.Context, scope, key string, response []byte) error {
	if err := s.q.CompleteIdempotencyKey(ctx, sqlcdb.CompleteIdempotencyKeyParams{Scope: scope, Key: key, Response: response}); err != nil {
		return fmt.Errorf("complete idempotency key: %w", err)
	}
	return nil
}

func (s *IdempotencyStore) Release(ctx context.Context, scope, key string) error {
	if err := s.q.ReleaseIdempotencyKey(ctx, sqlcdb.ReleaseIdempotencyKeyParams{Scope: scope, Key: key}); err != nil {
		return fmt.Errorf("release idempotency key: %w", err)
	}
	return nil
}
```

## 8. Integration tests

`main_test.go` and `pgtest` are in `../testing.md`, section 6. The constructors take the same arguments as the pgx adapters, so the contract test below and the section 7 tests of `pgx.md` run unchanged:

```go
// internal/orders/adapters/outbound/postgres/order_repository_test.go
//go:build integration

package postgres_test

import (
	"context"
	"errors"
	"testing"

	"shop/internal/orders/adapters/outbound/postgres"
	"shop/internal/orders/app"
	"shop/internal/orders/domain"
	"shop/internal/orders/orderstest"
)

func TestOrderRepository(t *testing.T) {
	orderstest.RunOrderRepositoryContract(t, func(t *testing.T) app.OrderRepository {
		return postgres.NewOrderRepository(cleanPool(t))
	})
}

func TestUnitOfWorkCommitsWhenFnSucceeds(t *testing.T) {
	pool := cleanPool(t)
	placeOrder := app.NewPlaceOrder(postgres.NewUnitOfWork(pool), &orderstest.SequentialIDs{}, orderstest.NewFixedClock())

	out, err := placeOrder.Execute(context.Background(), orderstest.PlaceOrderInput())
	if err != nil {
		t.Fatal(err)
	}

	stored, err := postgres.NewOrderRepository(pool).Get(context.Background(), domain.OrderID(out.OrderID))
	if err != nil {
		t.Fatal(err)
	}
	if stored.Total().Amount() != 3000 || stored.PlacedAt() != orderstest.Now {
		t.Fatalf("stored = %+v", stored.Snapshot())
	}
}

func TestUnitOfWorkRollsBackWhenFnFails(t *testing.T) {
	pool := cleanPool(t)
	failure := errors.New("boom")

	err := postgres.NewUnitOfWork(pool).Do(context.Background(), func(tx app.Tx) error {
		if err := tx.Orders().Add(context.Background(), orderstest.Order(t, "order-1")); err != nil {
			return err
		}
		return failure
	})

	if !errors.Is(err, failure) {
		t.Fatalf("err = %v, want the fn error", err)
	}
	_, err = postgres.NewOrderRepository(pool).Get(context.Background(), "order-1")
	if !errors.Is(err, domain.ErrOrderNotFound) {
		t.Fatalf("order survived the rollback: err = %v", err)
	}
}
```

## 9. Migrations

Identical to `pgx.md`, section 9: goose files in `migrations/`, embedded with `embed.FS`, applied by a deploy step. sqlc reads the same files, so a migration and the queries that depend on it change in one commit, and `sqlc generate` fails if a query references a column that does not exist.

## 10. Pitfalls

- **Returning generated structs** (`sqlcdb.GetOrderRow`) from the adapter or accepting them in the use case: they are persistence models.
- **Editing generated files.** Change the query or the config and regenerate.
- **One query file per table with CRUD for everything.** Write the queries the ports need, named for what they do.
- **`SELECT *`** in a query: the generated struct changes shape whenever a migration adds a column. List the columns.
- **Forgetting the timestamp override**: `pgtype.Timestamptz` leaks into mapping code; and remember `.UTC()` when mapping.
- **Dynamic filters.** sqlc wants static SQL. Use `sqlc.narg` with `IS NULL OR` for optional filters, or a hand-written pgx query in the same adapter for truly dynamic search.
